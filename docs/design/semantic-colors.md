# Design B 성공·주의·오류 색 기준

2026-11-13 · [Client #30 / IPGO-29](https://github.com/IpgoITGO/ipgo-client/issues/30)

현재 Design B를 기준으로 하며 실행 값의 정본은
[`src/styles/tokens.css`](../../src/styles/tokens.css)입니다. 2026-10-27 이슈의 설계 표와
당시 `tokens.css` 값은 과거 기록입니다. 과거 UI 시안 PDF의 색을 이 표보다 우선하지 않습니다.
새 디자인으로 기준을 바꿀 때는 이 문서와 토큰을 함께 수정합니다.

## 확정 값

| 의미 | 글자·표시 토큰 | 값 | 배경 토큰 | 값 | 글자 / 전용 배경 대비 |
| --- | --- | --- | --- | --- | --- |
| 성공·완료 | `--color-success` | `#007a60` | `--color-success-bg` | `#e2f8f1` | 4.79:1 |
| 주의·확인 필요 | `--color-warning` | `#a85a00` | `--color-warning-bg` | `#fff2d6` | 4.58:1 |
| 오류·위험 | `--color-danger` | `#c8261c` | `--color-danger-bg` | `#fff0ec` | 5.05:1 |

성공색은 기존 Design B의 `#04876a`에서 조금 진하게 보정했습니다. 기존 값은 전용 배경에서
4.046:1, 흰 배경에서 4.488:1로 일반 글자 기준에 미달했습니다. 사용자가 2026-11-13
성공색만 최소 조정하도록 승인했으며 성공 배경·주의·오류색은 유지합니다.
보정 후 성공색은 흰 배경에서 5.31:1, 기본 페이지 배경에서 4.94:1,
`--color-primary-soft`에서 4.60:1입니다. 색 토큰 추가나 화면별 덮어쓰기는 하지 않습니다.

## 사용과 대비 기준

- 상태 글자와 표시에는 위 의미 토큰을 쓰고 색 값을 화면별로 복사하지 않습니다.
- 연한 상태 배경에는 대응하는 의미 색의 글자를 사용합니다. 배경색만으로 상태를 전달하지
  않으며 기존 상태 문구·오류 안내·충족/미충족 표시를 함께 유지합니다.
- 일반 글자는 4.5:1 이상, 큰 글자(24px 이상 또는 18.67px 이상 굵은 글자)는 3:1 이상입니다.
  의미를 전달하는 비문자 표시에는 인접 배경과 3:1 이상을 적용합니다.
- 판정은 반올림 전 수치로 하며 표의 두 자리 숫자는 표시용입니다. 반투명·이미지 배경이나
  다른 색과의 새 조합은 실제 렌더링 배경을 포함해 다시 확인합니다.

근거: [WCAG 2.2 글자 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html),
[비문자 대비](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html).

## 화면 검증 범위

검증 기준 소스는 `c49b3488d49db1c727e5fc7d53a63387fed36563`의 Design B이며
이 변경의 성공색 보정을 적용해 전후를 대조합니다. Chromium에서 실제 앱 컴포넌트를 렌더링하고
계산된 글자색·배경색·글자 크기·굵기를 읽어 상대 휘도 식으로 대비를 계산합니다.
배경은 투명한 조상을 포함해 합성하고 각 화면의 스크린샷도 확인합니다.

| 화면과 상태 | 확인할 의미 색 |
| --- | --- |
| 로그인 빈 값 제출 | 오류 안내 |
| 회원가입 이메일 중복 확인 완료 | 성공 안내 |
| 회원가입 비밀번호 조건 일부 충족 | 성공·미충족 오류 글자 |
| 가입 완료 후 로그인 화면 | 성공 배경의 완료 안내 |
| 상품 상세 계산 완료·정확도 표시 | 성공 배경의 상태 배지 |
| 상품 상세 계산 전 | 주의 배경의 상태 배지 |

데스크톱 1280×960과 모바일 390×844에서 같은 상태를 확인합니다.
API는 로컬 합성 응답으로 제한하고 외부 요청과 미정의 API는 차단합니다.
이는 실제 컴포넌트의 화면 대비 검증이며 실서버 회원가입·계산 정확도·운영 배포 검증은 아닙니다.
서비스 전체 화면·모든 상호작용·모든 비문자 표시의 WCAG 적합성을 보증하지 않습니다.
최종 검사 결과와 확인한 commit은 연결된 PR과 이슈에 기록합니다.
